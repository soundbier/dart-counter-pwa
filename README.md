# dart-counter-pwa
Progressive Web App (PWA) für Dartzählen


Cloudflare Pages Build-Einstellungen
Wenn du dein GitHub-Repository mit Cloudflare Pages verknüpfst, brauchst du folgende Build-Konfiguration:

Framework preset: Vite

Build command: npm run build

Build output directory: dist

Root directory: / (leer lassen, falls es im Hauptverzeichnis liegt)
